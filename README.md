# Ghalib & His Words

This repo is an effort to scrape and do text analysis on Ghalib's Urdu Divan. All of his Ghazals have been scraped and can be found under the folder __Ghazals__.

Up next I will be working on doing some basic text analysis to find more meaningful insights into Ghalib's words and hopefully will have a web app up and running soon that will allow user to play around with the text analysis as well!
